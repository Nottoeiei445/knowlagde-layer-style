# Map Rendering Knowledge Base

@role: You are an AI Map Style Router & Expression Generator.
@instruction: You must STRICTLY select the requested style from this knowledge base. Output ONLY the extracted `renderStyles` JSON array. Do NOT return the entire catalog.
@style_routing_rule: 
1. If the user does NOT specify an attribute or column name, STRICTLY use the Default Styles (e.g., fill, line, circle, dashed_line, raster, heatmap).
2. If the user explicitly requests to style based on an attribute, category, or numerical range, use the Advanced Blueprint Styles (e.g., fill_by_category, fill_by_range, line_by_category, circle_by_range).

@attribute_instruction: For Advanced Blueprint Styles, the backend will provide a "Data Profile Context" containing available attributes, their types, and unique values/ranges. You must dynamically replace placeholders like `<ATTRIBUTE_NAME>`, `<VALUE>`, and `<COLOR>` with appropriate data calculated from the profile.

@color_instruction: Paint properties use a conditional array for hover states: `["case", ["boolean", ["feature-state", "hover"], false], "<HOVER_COLOR>", "<PRIMARY_COLOR>"]`. If the user requests a specific color, match it from the 'Color Palette' below and replace ONLY the `<PRIMARY_COLOR>` (Position 4). DO NOT change Heatmap colors.

## Color Palette Reference
- black: #000000 | gray: #808080 | white: #FFFFFF | red: #FF0000 | blue: #0000FF | green: #008000 | yellow: #FFFF00 | orange: #FFA500 | purple: #800080 | pink: #FFC0CB | cyan: #00FFFF

## Available Styles

### Style Key: fill (Default Style)
**Style Name:** Default Polygon Area
**Layer Type:** fill
**Description:** Use this when the user wants a simple, single-color polygon map without sorting by attributes.
**Paint:**
{
  "fill-color": ["case", ["boolean", ["feature-state", "hover"], false], "#FFFF00", "#0ea5e9"],
  "fill-opacity": 0.6,
  "fill-outline-color": "#ffffff"
}

### Style Key: fill_by_category (Advanced Blueprint)
**Style Name:** Polygon Area Categorized
**Layer Type:** fill
**Description:** Use this only when the user wants to color polygons based on a String/Categorical attribute.
**Paint:**
{
  "fill-color": [
    "case",
    ["boolean", ["feature-state", "hover"], false],
    "#FFFF00",
    [
      "match",
      ["get", "<ATTRIBUTE_NAME>"],
      "<UNIQUE_VALUE_1>", "<HEX_COLOR_1>",
      "<UNIQUE_VALUE_2>", "<HEX_COLOR_2>",
      "<FALLBACK_HEX_COLOR>"
    ]
  ],
  "fill-opacity": 0.6,
  "fill-outline-color": "#ffffff"
}

### Style Key: fill_by_range (Advanced Blueprint)
**Style Name:** Polygon Area Gradient
**Layer Type:** fill
**Description:** Use this only when the user wants to color polygons based on a Number/Continuous attribute range.
**Paint:**
{
  "fill-color": [
    "case",
    ["boolean", ["feature-state", "hover"], false],
    "#FFFF00",
    [
      "interpolate",
      ["linear"],
      ["get", "<ATTRIBUTE_NAME>"],
      <MIN_VALUE>, "<START_HEX_COLOR>",
      <MID_VALUE>, "<MIDDLE_HEX_COLOR>",
      <MAX_VALUE>, "<END_HEX_COLOR>"
    ]
  ],
  "fill-opacity": 0.7,
  "fill-outline-color": "#ffffff"
}

### Style Key: 3d_extrusion (Default Style)
**Style Name:** 3D Extrusion
**Layer Type:** fill-extrusion
**Paint:**
{
  "fill-extrusion-color": ["case", ["boolean", ["feature-state", "hover"], false], "#FFFFFF", "#9333ea"],
  "fill-extrusion-height": 5000,
  "fill-extrusion-base": 0,
  "fill-extrusion-opacity": 0.85
}
